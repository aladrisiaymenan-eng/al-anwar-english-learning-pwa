# النظرة التقنية وسير العمل

## بنية التطبيق

المشروع تطبيق ويب ثابت لا يحتاج إلى خادم أو قاعدة بيانات. `index.html` يحتوي الواجهة والتفاعل، وبيانات المسارات محفوظة في ملفات JSON ومقابلات JavaScript لتشغيل مباشر. `manifest.webmanifest` يصف التطبيق المثبت، بينما يسجل `pwa.js` عامل الخدمة ويعرض حالة الاتصال وسلوك التثبيت.

## سير الطالب

1. إرشاد البداية واختيار اختبار المستوى أو تجاوزه إلى A1.
2. فتح المسار، ودراسة المفردات والقواعد.
3. استخدام الحفظ والمراجعة اليومية ومراجعة التحليلات.
4. إجراء اختبار المسار.
5. فتح المسار التالي بعد نتيجة 70% أو أكثر.

## العمل دون اتصال

يجلب `service-worker.js` الملفات الأساسية إلى Cache Storage عند التثبيت، ويعرض نسخة مخزنة عند تعذر الشبكة. يتطلب ذلك زيارة أولى عبر HTTPS وإتمام تنزيل الملفات. تُخزن حالة الطالب باستخدام تخزين المتصفح محليًا، وليس في السحابة. حذف بيانات المتصفح قد يحذف التقدم.

## محتوى التعليم

يتضمن المنهج تسعة مسارات من A1 إلى C2 وثلاثة مسارات إثرائية. تضم ملفات الدورة الكلمات والجمل والترجمات والدروس النحوية والاختبارات. اختبار تحديد المستوى يقدم توصية تقريبية استنادًا إلى أسئلة ومهارات محلية؛ لا يصدر شهادة ولا ينبغي اعتباره بديلًا لاختبار معياري معتمد.

## تطوير بيانات المسارات

يُحرر المصدر المنظم `data/curriculum.json`، وتُحدّث نسخة التشغيل `data/curriculum.js` وأي ملفات مشتقة للدورات بواسطة أدوات المزامنة الموجودة في `tools/`. حافظ على الحقول ومعرّفات العناصر حتى لا تتأثر حالة التقدم المحفوظة.

## النشر

المشروع جاهز للاستضافة الثابتة على HTTPS. إعداد GitHub Pages ينشر جذر المستودع من الفرع الرئيسي. لا يوجد build command أو backend. بعد كل تحديث للملفات، يُعاد النشر تلقائيًا عبر GitHub Pages.

## الخصوصية والملكية

لا يستخدم المشروع تسجيل دخول أو خدمة تحليل خارجية. بيانات الطالب محلية. المستودع عام للقراءة والتنزيل، لكن لا يوجد ترخيص مفتوح مضاف؛ لا تفترض أن ذلك يمنح حق إعادة نشر المحتوى أو الاستخدام التجاري.
